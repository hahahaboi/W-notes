# W-notes

A modern Android note-taking app focused on speed, simplicity, and creativity.

W-notes aims to become more than a traditional notes app. The long-term goal is to combine structured note-taking, journaling, and free-form creative thinking into a single experience.

---

# Current Version

## Features

- Create notes
- Edit notes
- Save notes
- Organize notes
- Clean and minimal interface
- Fast local storage
- Designed using Jetpack Compose

# Version 2 — Booklets

Booklets are designed for sequential writing.

Instead of independent notes, pages exist in order, making them ideal for:

- Daily journals
- Diaries
- Research logs
- Project documentation
- Class notes
- Story writing
- Habit tracking

Planned features:

- Sequential pages
- Automatic page numbering
- Chapters
- Bookmarks
- Search
- Progress tracking
- Chronological ordering
- Optional manual reordering

---

# Version 3 — Sticker System

One of the biggest planned features.

Users will be able to convert content into reusable stickers.

## Text Stickers

Turn any note into a reusable text sticker.

Examples:

- Quotes
- Templates
- Checklists
- Frequently used notes

## Image Stickers

Import any image into the sticker library.

Examples:

- Diagrams
- Photos
- Icons
- Sketches

## Sticker Library

A native storage inside the app containing all stickers.

Available anywhere inside W-notes.

Users can:

- Save stickers
- Organize stickers
- Reuse stickers
- Delete stickers

# Notice Board Experience

Instead of only typing notes, users can build pages visually.

Example workflow:

Image Sticker

↓

Text Sticker

↓

Another Image

↓

Another Text Sticker

↓

Free handwriting (future)

↓

More stickers

Like pinning information onto a real notice board.

# Long-Term Vision

W-notes is intended to become an all-in-one thinking space.

Instead of separating:

- Notes
- Journals
- Visual boards
- Templates
- Research

everything should exist naturally inside one application.

The goal is to provide users with the freedom to write, organize, and think in whichever way feels most natural.
